# Appedor-
Appedor is a NAFDAC-approved weight gain supplement with Cyproheptadine, Lysine, and essential vitamins. Designed for undernourished individuals who struggle to eat, it gently restores appetite and supports healthy weight gain in Nigeria.
# Appedor Mini Website

This repository contains the **mini website for Appedor**, a NAFDAC-approved weight gain supplement designed to help undernourished individuals regain appetite and support healthy weight gain.

The website features:
- Product showcase with key benefits
- Testimonials from users
- Educational blogs (loaded dynamically from `blogs.json`)
- Contact section with clickable phone number and WhatsApp link
